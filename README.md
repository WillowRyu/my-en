# my-en

한국어를 쓰는 성인 영어 초보를 위한 개인 학습 웹앱. 채팅에 매번 요청하지 않고 **오늘 공부 시작**을 누르면 다음 작은 수업을 안내합니다. 여행·일상은 첫 코스의 임시 주제입니다.

## 사용하기

현재 이 Mac에는 의존성, 실제 음성 WAV 15개, 빌드 결과가 준비되어 있습니다. 개발 서버와 미리보기는 필요할 때 아래 명령으로 실행하세요. 터미널을 열어 둔 상태로 사용하고, 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다.

### 완성된 앱 체험

```sh
cd /Users/ryu-medi/Desktop/projects/my-en
npm run preview
```

프로덕션/PWA 미리보기: http://127.0.0.1:4186 . 현재 빌드 결과를 사용합니다. 소스 코드를 수정했다면 `npm run build`를 먼저 실행하세요.

### 개발할 때

```sh
cd /Users/ryu-medi/Desktop/projects/my-en
npm run dev
```

개발 화면: http://127.0.0.1:5186 . 수정 내용이 바로 반영됩니다. 개발 서버에서는 서비스 워커를 등록하지 않습니다. 현재 확인한 실행 환경은 Node 24.2.0 / npm 11.3.0이며, 프로젝트의 Node 지원 범위는 `package.json`의 `engines`에 기록되어 있습니다. 기존 설치를 사용하는 동안 `npm ci`나 음성 생성을 매번 다시 실행할 필요는 없습니다.

### 새 체크아웃을 준비할 때

```sh
npm ci
npm run audio:generate
npm run check
npm run preview
```

WAV는 공개 공유 제한 때문에 Git에서 제외했습니다. 음성 생성에는 macOS에 설치된 Samantha 음성과 로컬 음성 서비스 접근이 필요합니다. 다른 환경에서는 직접 소유한 WAV를 제공해야 합니다.

미리보기에서 “오프라인 준비됨” 표시가 나온 뒤 화면과 15개 음성을 인터넷 없이 다시 사용할 수 있습니다. 준비 전, 브라우저 저장소 삭제 후, 새 버전 캐시 완료 전에는 오프라인을 보장하지 않습니다. 업데이트는 기존 앱 탭을 모두 닫고 다시 열 때 적용되는 기본 서비스 워커 수명을 따릅니다.

두 서버 모두 `127.0.0.1` + `strictPort` 사용. 개발 5186 / 미리보기 4186을 my-en 전용으로 사용하며, Kuji의 5173/4100/54328/8029/54329와 분리했습니다. 바인딩 실패 시 기존 프로세스를 종료하지 말고 먼저 원인을 확인하세요. 테스트에서만 OS가 할당한 독립 임시 포트를 추가 사용합니다. 사용자 휴대폰 접속용 LAN/HTTPS 노출은 설정하지 않았습니다. 원격 기기의 마이크와 PWA는 안전한 HTTPS 환경이 필요합니다.

개발 화면과 미리보기는 포트가 달라 학습 기록도 별도로 저장됩니다. 기록을 옮기려면 설정의 JSON 내보내기·복원을 사용하세요.

## 첫 버전에 들어 있는 것

- 첫 7일, 하루 새 표현 2~3개(총 15개), 이전 표현 재사용. 정규 수업은 하루 하나를 자동 선택하고 같은 날은 짧은 재연습을 안내합니다.
- 모범 음성 듣기 → 한국어 뜻 선택 → 단어 순서 맞추기 → 보고 따라 말하기 → 문장을 가린 회상. 녹음과 회상은 건너뛸 수 있습니다.
- 실제 포함 WAV 재생과 0.75배 천천히 듣기. 버튼/브라우저 권한으로만 마이크를 요청하고 MediaRecorder로 녹음·재생. 최대 30초, 외부 전송 없이 브라우저 메모리에만 보관. 단계 이동·새로고침 시 녹음 제거.
- 자동 로컬 저장·새로고침·뒤로가기·이어하기. lesson/phrase 버전, 시도와 힌트, 세 가지 skill별 복습 상태 분리.
- 1/3/7/14일 초기 복습 규칙(설정 가능). 과학적으로 최적인 간격이라고 주장하지 않습니다. 결석 벌점 없음. 새 수업의 재사용/복습은 최대 2표현, 별도 복습은 최대 3표현으로 제한.
- 바쁜 날 두 표현만 하는 약 5분 모드. 정규 수업 완료로 계산하지 않습니다. 정규 수업도 내 속도로 짧게 끝낼 수 있으며 시간 제한·할당량 강제 없음.
- 백업 JSON 내보내기·확인 후 복원·직전 저장본 복구·확인 후 초기화. 손상/미지원 버전 기록은 자동 덮어쓰기 차단. 브라우저 저장 실패 시 백업 안내.
- 한국어 안내, 큰 버튼, 키보드 포커스/본문 건너뛰기, 모바일/데스크톱 레이아웃, PWA 아이콘/매니페스트와 버전별 캐시.

듣고 뜻을 선택한 기록, 보고 따라 말한 **자기 확인**, 힌트 없이 떠올린 **자기 확인**을 구분합니다. 정답 선택이나 녹음만으로 말하기 숙달·발음 점수를 표시하지 않습니다. 음성 실패/마이크 거부/지원 부족은 학습 오답으로 기록하지 않습니다.

## 검증 명령

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

이 작업에서는 다른 프로젝트의 브라우저 캐시를 변경하지 않도록 다음 전용 경로를 썼습니다:

```sh
PLAYWRIGHT_BROWSERS_PATH=/tmp/my-en-playwright npx playwright install chromium webkit
PLAYWRIGHT_BROWSERS_PATH=/tmp/my-en-playwright npm run test:e2e
```

`test:e2e`는 4186에 자신의 미리보기 서버를 시작하고 종료합니다. 이미 실행 중인 미리보기와 겹치면 실패하므로 my-en 미리보기만 먼저 닫으세요. 테스트 결과: [PROGRESS.md](PROGRESS.md), 검증 화면: [docs/screenshots](docs/screenshots). 테스트 녹음은 합성 스트림으로 실제 MediaRecorder/재생/트랙 해제를 확인합니다. 사용자 실기기 마이크·iPhone 설치·사람이 들은 음질 검증은 별도입니다.

## 음성 자산과 공개 전 조건

문장과 뜻은 이 프로젝트에서 직접 작성했습니다. 타 서비스 수업/음성 복사 없음. 음성은 이 Mac에 설치된 macOS Samantha로 로컬 생성했습니다. 외부 API, 기존 API 키, 음성 업로드, 토큰 생성, 비용 발생 없음.

Apple의 [macOS 라이선스 2F](https://www.apple.com/legal/sla/docs/macOSGoldenGate.pdf)는 시스템 음성으로 만든 원본 콘텐츠를 개인 비상업적 용도로 제한하며 공개 공유/재배포를 허용하지 않습니다. **현재 WAV와 이를 포함한 dist는 공개 푸시·배포하지 마세요.** 공개가 결정되면 직접 녹음 또는 재배포 가능한 음성 자산으로 교체해야 합니다. `public/audio/manifest.json`에 텍스트와 출처가 기록됩니다. 음성 생성기는 빈 WAV를 감지해 실패합니다. macOS 음성 서비스 접근이 차단된 환경에서는 직접 소유한 자산을 제공해야 합니다.

## 다음 작업과 구조

무료 개인 사용의 작은 앱이 현재 범위입니다. 로그인/동기화/자유채팅/자동 발음평가/외부 AI/푸시/스토어 패키징/CI·배포는 구현하지 않았습니다.

- `src/content.ts`: lesson/phrase/module 콘텐츠 및 8개 확장 모듈.
- `src/model.ts`: 자동 수업 선택, 시도 기록, skill별 복습, 날짜·버전 스키마.
- `src/storage.ts`: 검증, 저장, 백업. 이 브라우저/출처별 데이터이며 다른 포트·브라우저에는 자동 이동하지 않습니다.
- `src/Study.tsx`, `src/Media.tsx`, `src/audio.ts`: 학습 UI, 로컬 녹음, 교체 가능한 음성 adapter 계약.
- `scripts/build-sw.mjs`: 포함 자산의 해시 기반 오프라인 캐시와 오디오 Range 응답.
