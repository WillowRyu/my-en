# my-en

한국어 사용자를 위한 개인 영어 학습 웹앱. **오늘 공부 시작**을 누르면 설명·대화·문장 응용을 순서대로 안내합니다. 기초가 쉽다면 실용 문장부터, 더 익숙하면 문장 확장부터 선택할 수 있습니다. 공인 영어 수준을 자동 확정하지 않습니다.

## 사용하기

현재 이 Mac에는 의존성, 실제 음성 WAV 31개(표현 15개 + 단어 16개), 빌드 결과가 준비되어 있습니다. 개발 서버와 미리보기는 필요할 때 아래 명령으로 실행하세요. 터미널을 열어 둔 상태로 사용하고, 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다.

### 완성된 앱 체험

```sh
cd /Users/ryu-medi/Desktop/projects/my-en
npm run preview
```

프로덕션/PWA 미리보기: http://127.0.0.1:4186 . 현재 빌드 결과를 사용합니다. 소스 코드를 수정했다면 `npm run build`를 먼저 실행하세요.

### 개발할 때

```sh
cd /Users/ryu-medi/Desktop/projects/my-en
npm run dev
```

개발 화면: http://127.0.0.1:5186 . 수정 내용이 바로 반영됩니다. 개발 서버에서는 서비스 워커를 등록하지 않습니다. 현재 확인한 실행 환경은 Node 24.2.0 / npm 11.3.0이며, 프로젝트의 Node 지원 범위는 `package.json`의 `engines`에 기록되어 있습니다. 기존 설치를 사용하는 동안 `npm ci`나 음성 생성을 매번 다시 실행할 필요는 없습니다.

### 새 체크아웃을 준비할 때

```sh
npm ci
npm run audio:generate
npm run check
npm run preview
```

WAV는 공개 공유 제한 때문에 Git에서 제외했습니다. 음성 생성에는 macOS에 설치된 Samantha 음성과 로컬 음성 서비스 접근이 필요합니다. 다른 환경에서는 직접 소유한 WAV를 제공해야 합니다.

미리보기에서 “오프라인 준비됨” 표시가 나온 뒤 화면과 표현·단어 음성을 인터넷 없이 다시 사용할 수 있습니다. 준비 전, 브라우저 저장소 삭제 후, 새 버전 캐시 완료 전에는 오프라인을 보장하지 않습니다. 업데이트는 기존 앱 탭을 모두 닫고 다시 열 때 적용되는 기본 서비스 워커 수명을 따릅니다.

두 서버 모두 `127.0.0.1` + `strictPort` 사용. 개발 5186 / 미리보기 4186을 my-en 전용으로 사용하며, Kuji의 5173/4100/54328/8029/54329와 분리했습니다. 바인딩 실패 시 기존 프로세스를 종료하지 말고 먼저 원인을 확인하세요. 테스트에서만 OS가 할당한 독립 임시 포트를 추가 사용합니다. 사용자 휴대폰 접속용 LAN/HTTPS 노출은 설정하지 않았습니다. 원격 기기의 마이크와 PWA는 안전한 HTTPS 환경이 필요합니다.

개발 화면과 미리보기는 포트가 달라 학습 기록도 별도로 저장됩니다. 기록을 옮기려면 설정의 JSON 내보내기·복원을 사용하세요.

## 설명과 응용으로 공부하기

기본 시작점은 **실용 문장**입니다. 오늘 화면의 “난이도와 시작점 바꾸기”에서 기초 단어·표현 / 실용 문장 / 문장 확장을 선택합니다. 선택형 6문제는 시작점 제안이며 듣기·말하기·공인 수준 평가가 아닙니다. 제안을 무시하고 원하는 과정으로 바꿀 수 있습니다. 수업 목록에서 아는 수업을 건너뛰거나 되돌리고, 원하는 수업부터 시작할 수 있습니다. 건너뛰기는 완료·숙달로 표시하지 않습니다.

새 콘텐츠는 **실용 6 + 확장 7 = 13수업**입니다. 과거 경험·계획·이유·비교·요청·문제 해결에 이어 과거진행·경험 현재완료·조건문·조언·관계절·기간·간접질문을 연습합니다. 총 한국어 설명 26개, 예문 39개, 8턴 상황 대화 13개(104턴), 대화 확인 26개, 문장 변형 39개, 자기 답변 26개, 지연 회상 26개입니다. 첫 수업에 인사만 반복하지 않습니다.

1. 필요한 회상 최대 2개를 문장을 가리고 확인합니다.
2. 한국어 문법·뉘앙스·혼동하기 쉬운 구조와 예문을 읽습니다.
3. 8턴 대화의 역할을 읽고 의미·이유를 두 문제로 확인합니다. 한국어 뜻은 펼쳐 볼 수 있습니다.
4. 시제·주어·이유·의도를 바꿔 문장을 3번 직접 씁니다.
5. 실제 또는 가상의 상황에 2~3문장 답변을 2번 씁니다. 예문과 이유, 의도·구조 확인 항목으로 비교합니다.
6. 수업 경험과 회상 확인을 분리합니다. 기본 3일 뒤에 힌트 없는 회상 2개를 예약합니다. 한 회차 15~25분은 내용·연습량의 설계 목표이며 시간이나 학습효과 보장이 아닙니다.

제한된 문장 변형은 여러 작성 답안과 대소문자·문장부호·일부 축약형을 허용합니다. 다른 표현은 자동 오답으로 단정하지 않고 비교 안내를 제공합니다. 몇 가지 명시한 흔한 구조 오류만 이유를 설명합니다. **자유 답변은 자동 문법·자연스러움 평가 없이 자기 확인**으로 기록합니다. 회상도 내 확인이며 발음·문법 숙달 점수가 아닙니다. 입력·힌트·단계는 저장되고, 답안이나 피드백을 본 뒤 고친 답은 힌트 없는 회상 성공으로 계산하지 않습니다.

새 수업은 읽고 쓰는 기본 진행이며 소리 내어 읽기는 선택입니다. 새 음성 제작·외부 AI·유료 서비스는 사용하지 않았습니다. 기존 31개 음성·16개 단어·7일 기초 과정과 그 기록·설정은 유지합니다. 기초 수업과 설명·응용 수업은 각각 이어할 자리를 보존합니다.

## 현재 가능한 학습

- 핵심 단어 16개에서 수업에 연결된 새 단어를 하루 2개부터 시작(설정에서 1~3개). 짧은 공부는 새 단어 최대 1개. 영어→뜻 선택, 뜻→영어 직접 쓰기, 방향별 오답·힌트·간격 복습. 음성은 선택이고 텍스트 기본 버튼만으로도 완료할 수 있습니다. 같은 날 여러 번 공부해도 새 단어 수는 하루 설정을 넘지 않습니다.
- 첫 7일, 하루 새 표현 2~3개(총 15개), 이전 표현 재사용. 정규 수업은 하루 하나를 자동 선택하고 같은 날은 짧은 재연습을 안내합니다.
- 단어 뜻·소리 → 양방향 단어 회상 → 관련 짧은 문장. 문장은 모범 음성 듣기 → 한국어 뜻 선택 → 단어 순서 맞추기 → 보고 따라 말하기 → 문장을 가린 회상. 녹음과 회상은 건너뛸 수 있습니다.
- 실제 포함 WAV 재생과 0.75배 천천히 듣기. 버튼/브라우저 권한으로만 마이크를 요청하고 MediaRecorder로 녹음·재생. 최대 30초, 외부 전송 없이 브라우저 메모리에만 보관. 단계 이동·새로고침 시 녹음 제거.
- 자동 로컬 저장·새로고침·뒤로가기·이어하기. lesson/phrase 버전, 시도와 힌트, 듣기·문장 조합·말하기·회상별 복습과 단어 두 방향 기록 분리.
- 1/3/7/14일 초기 복습 규칙(설정 가능). 예약일이 지난 뒤 다른 날에 확인할 때만 간격을 늘리며, 당일·예약 전 재연습은 기존 간격을 유지합니다. 복습은 예약된 단계만 제시하고 문장 조합 오답도 재학습 대상으로 남깁니다. 과학적으로 최적인 간격이라고 주장하지 않습니다. 결석 벌점 없음. 새 수업의 재사용/복습은 최대 2표현, 별도 복습은 최대 3표현으로 제한.
- 바쁜 날 두 표현만 하는 약 5분 모드. 정규 수업 완료로 계산하지 않으며 같은 날 정규 수업을 이어서 시작할 수 있습니다. 별도 복습 완료도 정규 수업을 막지 않습니다. 정규 수업도 내 속도로 짧게 끝낼 수 있으며 시간 제한·할당량 강제 없음.
- v1·v2 기록·JSON 백업을 v3로 이관(진행 중 단계·시도·날짜·설정·진도 유지). 기존 저장 키 유지, 읽을 때 자동 쓰기 없음, 첫 업데이트 전 원본 별도 보관. v1 원본은 `my-en:migration:v1`, v2 원본은 `my-en:migration:v2`에 각각 별도 보관하며 원본 보관에 실패하면 새 형식 저장을 중단합니다. v3 백업은 구버전 앱에서 열 수 없습니다.
- 백업 JSON 내보내기·확인 후 복원·직전 저장본 복구·확인 후 초기화. 손상/미지원 버전 기록은 자동 덮어쓰기 차단. 브라우저 저장 실패 시 백업 안내. 복원·설정·초기화는 실제 저장 성공 때만 성공 안내하며, 직전 백업 저장만 실패한 경우도 따로 알립니다.
- 한국어 안내, 큰 버튼, 키보드 포커스/본문 건너뛰기, 모바일/데스크톱 레이아웃, PWA 아이콘/매니페스트와 버전별 캐시.

듣고 뜻을 선택한 기록, 보고 따라 말한 **자기 확인**, 힌트 없이 떠올린 **자기 확인**을 구분합니다. 정답 선택이나 녹음만으로 말하기 숙달·발음 점수를 표시하지 않습니다. 음성 실패/마이크 거부/지원 부족은 학습 오답으로 기록하지 않습니다.


`test:e2e`는 4186에 자신의 미리보기 서버를 시작하고 종료합니다. 이미 실행 중인 미리보기와 겹치면 실패하므로 my-en 미리보기만 먼저 닫으세요. 테스트 결과: [PROGRESS.md](PROGRESS.md), 검증 화면: [docs/screenshots](docs/screenshots). 테스트 녹음은 합성 스트림으로 실제 MediaRecorder/재생/트랙 해제를 확인합니다. 사용자 실기기 마이크·iPhone 설치·사람이 들은 음질 검증은 별도입니다.

## 음성 자산과 공개 전 조건

문장과 뜻은 이 프로젝트에서 직접 작성했습니다. 타 서비스 수업/음성 복사 없음. 음성은 이 Mac에 설치된 macOS Samantha로 로컬 생성했습니다. 외부 API, 기존 API 키, 음성 업로드, 토큰 생성, 비용 발생 없음.

Apple의 [macOS 라이선스 2F](https://www.apple.com/legal/sla/docs/macOSGoldenGate.pdf)는 시스템 음성으로 만든 원본 콘텐츠를 개인 비상업적 용도로 제한하며 공개 공유/재배포를 허용하지 않습니다. **현재 WAV와 이를 포함한 dist는 공개 푸시·배포하지 마세요.** 공개가 결정되면 직접 녹음 또는 재배포 가능한 음성 자산으로 교체해야 합니다. `public/audio/manifest.json`에 텍스트와 출처가 기록됩니다. 음성 생성기는 빈 WAV를 감지해 실패합니다. `npm run audio:generate`는 31개를 생성하며, 기존 표현 음성을 보존하고 새 단어 16개만 만들려면 `npm run audio:words`를 사용합니다. macOS 음성 서비스 접근이 차단된 환경에서는 직접 소유한 자산을 제공해야 합니다.
