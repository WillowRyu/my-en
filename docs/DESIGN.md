# my-en 디자인 방향

한국어를 쓰는 성인 초보가 입력 없이 오늘의 작은 목표를 시작하는 개인 학습 공간.

색: 종이 흰색 #FFFFFF, 흐린 하늘 #F2F6FA, 깊은 파랑 #245BB5, 잉크 #193047, 보조 글자 #53677C, 완료 초록 #24684A. 중요 버튼에만 깊은 파랑을 쓴다.

글꼴: 한국어는 설치된 Apple SD Gothic Neo / Malgun Gothic, 영어 예문은 Georgia. 외부 폰트 호출 없음. 영어 예문에만 서체 차이를 주어 듣는 대상을 구분한다. 본문 17px 이상, 터치영역 48px 이상.

배치: 데스크톱은 조용한 왼쪽 내비게이션 + 넓은 학습 영역, 모바일은 상단 로고 + 하단 3개 내비게이션. 홈의 주인공은 인사말과 한 개의 큰 '오늘 공부 시작' 버튼. 동일한 카드들을 나열하지 않고 오늘 수업, 복습, 7일 여정을 다른 밀도로 표현한다. 왼쪽 정렬, 학습 화면은 적당한 너비로 중앙 배치.

```
my-en | 오늘은 인사 한마디부터
오늘  | [오늘 공부 시작]   [소리/시간 정보]
기록  | 기억을 깨우는 복습
설정  | 1일 ... 7일 작은 수업들
```

검토: 성인 초보에게 캐릭터·점수·연속 출석 압박을 주지 않는다. 7일 번호는 실제 순서에만 사용. 과장된 학습 시간 대신 '표현 2~3개, 내 속도로' 표시. 진행률은 수업 내 단계만 뜻하며 영어 실력이나 발음 점수가 아니다. 애니메이션은 버튼 응답에 제한하고 reduced-motion을 존중한다.
