# 첫 7일 학습 설계와 확장

대상: 한국어 사용자 성인 초보, 듣기/읽기 부담이 크고 매번 AI에게 학습을 요청하는 일이 불편한 사용자. 목표는 작은 표현을 이해하고 입으로 꺼내 보는 경험. 여행/일상은 임시 코스이며 `moduleId`, lesson 순서·상황을 바꿀 수 있다.

## 첫 코스 검토

2026-10-04 직접 작성 후 문장·한국어 의미 대응, 상황의 자연스러움, 정답 중복, 표현 수, 이전 표현 재사용 순서를 검토했다. 정답 보기는 한 개이며 비슷한 단어를 무작정 함정으로 사용하지 않는다. 자동 구조 검증 통과. 사용자 실제 난이도 피드백, 영어 교육 전문가 검토, 사람의 음질/발음 청취 검토는 아직 없다.

| 수업 | 작은 목표 | 새 표현 | 재사용 |
|---|---|---|---|
| 1 | 인사·이름·재요청 | Hello. / I'm Ryu. / Say that again, please. | 없음 |
| 2 | 반가움·감사 | Nice to meet you. / Thank you. | 인사·이름 |
| 3 | 물·커피 요청 | Water, please. / Coffee, please. | 감사 |
| 4 | 가격·카드 결제 | How much is it? / Can I pay by card? | 커피·감사 |
| 5 | 화장실 위치·거리 | Where is the restroom? / Is it near here? | 재요청 |
| 6 | 내 상태·휴식 | I'm hungry. / I need a break. | 물 |
| 7 | 제안 응답·작별 | That sounds good. / See you tomorrow. | 반가움·감사 |

Ryu는 연습용 이름임을 안내한다. 첫날 재요청 표현은 다른 표현보다 길지만 놓친 말을 다시 요청할 수 있도록 포함했다. 어려우면 단어 조합/문장 힌트/회상 재보기를 쓸 수 있다. 추후 실제 난이도에 따라 “Again, please.” 등 더 짧은 표현으로 버전을 나눠 교체할 수 있다. 글자 음역을 외워 발음한 것으로 판정하지 않는다.

## 단계와 기록의 의미

1. 듣기: 영어와 한국어 뜻을 같이 확인하고 포함 음성을 버튼으로 듣는다. 끝까지 재생한 뒤 뜻 선택으로 진행. 기술 문제는 듣기 확인을 건너뛴 별도 기록.
2. 뜻 선택: 모범 문장을 가리고 한국어 의미 선택. 재생 가능. 뜻 힌트에는 정답을 명시하되 사용 횟수 저장. 잘못 골라도 다시 시도.
3. 문장 조합: 한국어 의미를 보고 순서가 바뀐 영어 단어를 누른다. 힌트로 전체 문장 확인 가능. 조합 정답은 **말하기 숙달로 계산하지 않음**.
4. 따라 말하기: 문장/뜻/모범 음성을 보고 따라 말한다. 선택 녹음과 자기 재생. “따라 말했어요”는 자기 확인이며 성공 발음 점수 없음. 건너뛰기 가능.
5. 회상: 한국어 의미만 제시. 영어 문장/모범 음성을 가린다. 스스로 떠올림/어려움/다시보기/건너뛰기. 다시보기를 쓰면 힌트 없는 회상 성공으로 계산하지 않음.

`listening`: 실제 음성을 들은 후 뜻 선택 시도, 오답/뜻 힌트 여부로 다음 복습 간격 조정. `speaking`: 자기 확인 연습 횟수만 저장, 성공 점수 없이 1일 뒤 재확인. `recall`: 자기 확인+힌트 여부로 간격 조정. UI에는 말하기·회상의 자기 확인 성격을 명시한다. 세 상태를 합쳐 “완전 숙달”로 표시하지 않는다.

정규 수업은 새 표현 2~3개 + 이전/기한 도래 표현 최대 2개. 같은 날 다시 누르면 복습/재연습을 제공. 5분 모드는 최대 2개, 정규 수업 완료 수에 포함 안 함. 결석 기간만큼 분량이 커지지 않는다. 시간은 제한하지 않으며 15~20분을 채우려고 콘텐츠를 부풀리지 않는다.

## 복습/데이터 계약

- 초기 간격 `[1,3,7,14]`은 조절 가능한 운영 규칙. 첫 성공 후 1일, 다음 성공 후 3일, 7일, 14일; 이후 14일 유지. 어려움/힌트 사용은 첫 간격으로 재시작. 4개 양의 증가 정수, 최대 90일.
- 브라우저/마이크 실패의 건너뛰기는 skill 오답/퇴보로 계산하지 않으며 기존 해당 skill 예약도 바꾸지 않는다.
- `lesson.id/version`, `phrase.id/version`, `schemaVersion` 분리. `Attempt`: session, lesson/phrase 버전, step, outcome, hints, 시각. `Review`: phrase+skill 키, stage/due/lastAt/lastSession, evidence, successes/practices. `Session`: 순서·현재 표현·단계·힌트·선택 단어. `Completion`: session/lesson/version/mode/표현/day/timeZone.
- 날짜는 처음 저장한 IANA 시간대의 현지 날짜. 간격은 UTC 날짜 산술로 날짜만 더해 DST의 23/25시간 영향을 피함. 자정을 넘겨 완료하면 완료한 날 기록. 시간대 변경 시 기존 due의 달력 날짜는 유지, 이후 예약에 새 시간대 적용.
- 완료 세션 중복 방지. 직전 정상 저장본 하나 보관. 손상/미지원 콘텐츠 버전의 자동 덮어쓰기 금지. JSON 복원은 Zod로 검증 후 사용자 확인. 녹음은 영속화하지 않음.
- 수업/표현 버전을 실제로 올릴 때 이전 state migration을 먼저 설계해야 한다. 현재는 버전1만 지원하고 미지원 백업은 원본 보존/내보내기로 처리한다.

## 8모듈 확장 로드맵

현재 스키마의 `ModuleId`와 `modules` 목록이 경계다. 각 모듈은 대표 상황 + 하루 2~3표현 lesson + 재사용 reference + 음성 자산을 추가한다. 미래 콘텐츠는 아직 수업으로 제공하지 않는다.

| 모듈 | 다음 작은 목표 |
|---|---|
| 인사 | 도움 부탁, 대화 시작/재요청 |
| 숫자·시간·자기소개 | 시간·출신·나이, 숫자 듣기 |
| 카페 주문 | 크기/온도/포장, 상대 질문 듣기 |
| 일상 | 하루 행동과 상태 |
| 취미 | 좋아하는 활동 묻고 답하기 |
| 길 묻기 | 좌우/직진을 듣고 다시 확인 |
| 쇼핑 | 크기/색상/가격/결제 요청 |
| 약속 | 날짜/시간/장소 정하기 |

먼저 사용자 7일 체험으로 길이·음성·낯선 표현을 조정하고 콘텐츠 버전 정책을 확정한다. 다음은 독립 상황의 짧은 두 턴 대화, 사용자 이름/관심 주제 설정, 재배포 가능한 음성. 계정/동기화/외부 AI는 필요가 확인되고 비용·개인정보 승인 범위가 정해진 뒤 별도 설계한다.
