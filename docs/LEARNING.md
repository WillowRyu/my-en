# 설명·문장 응용과 기존 기초 학습 설계

대상: 한국어 사용자 성인 초보, 듣기/읽기 부담이 크고 매번 AI에게 학습을 요청하는 일이 불편한 사용자. 목표는 작은 표현을 이해하고 입으로 꺼내 보는 경험. 여행/일상은 임시 코스이며 `moduleId`, lesson 순서·상황을 바꿀 수 있다.

## 설명·실용 문장 과정 · 2026-10-11

사용자가 기존 내용이 너무 쉽고 짧으며 설명 부족으로 학습을 확인하기 어렵다고 피드백했다. 문법 전체를 먼저 끝내도록 요구하지 않고 사용할 문장에 필요한 구조·뉘앙스 설명을 곁들인다. 기존 기초는 보존하고 새 기본 시작점을 실용 문장으로 한다. 이는 사용자 요청에 맞춘 선택이며 공인 수준 진단 결과가 아니다.

| 과정 | 수업 | 사용하는 구조·상황 |
|---|---|---|
| 실용 | 주말 경험 | 과거형·did 부정/질문, 한 일과 하지 않은 일 |
| 실용 | 약속 조율 | going to·미래 약속 진행형, 시간 변경 |
| 실용 | 이유·대안 | because·so, 선택 이유와 다른 장소 |
| 실용 | 숙소 비교 | -er / more / than, 가격·거리·조식 비교 |
| 실용 | 정중한 요청 | would like·could you/I, 주문 조건 변경 |
| 실용 | 여행 중 문제 | there is/are·현재 문제·이미 한 시도·도움 요청 |
| 확장 | 전화 놓친 이유 | 과거진행·when/while, 배경과 사건 |
| 확장 | 해 본 경험 | have+과거분사에서 구체적 과거로 이어가기 |
| 확장 | 대안 계획 | 실현 가능한 if 조건·will/can |

| 확장 | 분실물 설명 | that/which/who 관계절, 대상 식별 |

13수업 각각 설명 2개, 예문 3개, 상황 대화 8턴, 확인 문제 2개, 변형 3개, 직접 답변 2개, 지연 회상 2개를 직접 작성했다. 총 설명26·예문39·대화104턴·확인26·변형39·직접답변26·지연회상26. glossary는 수업별 덩어리 뜻 안내이며 기존 영속 단어 16개를 추가 숙달로 기록하지 않는다. 기존 7수업·15표현·16단어·31음성은 삭제/재버전하지 않는다.

설명/예문 4~6분, 대화 확인 4~6분, 변형·자기 답변 7~11분을 예상한 15~25분 설계 목표다. 실사용 시간·학습효과는 아직 확인하지 않았으며 강제 타이머·분량 벌점은 없다. 입력은 읽고 쓰는 기본 진행이다. 역할을 소리 내어 읽는 것은 선택이며 새 수업 음성·음성 인식·외부 AI는 없다.

### 시작점과 건너뛰기

기초 / 실용 / 확장을 직접 선택하거나 객관식 6문제로 제한된 문장 구조 친숙도를 확인한다. 0~1개는 기초, 2~4개는 실용, 5~6개는 확장 시작점을 제안한다. 기준은 편의 규칙이며 CEFR·듣기·말하기 실력을 확정하지 않는다. 제안 적용은 사용자 선택이다. 선택은 언제든 바꿔도 기록이 남는다. 아는 수업 건너뛰기와 되돌리기, 원하는 수업 선택을 제공하며 건너뜀은 완료·숙달과 분리한다.

### 답변 평가 계약

- 대화 확인은 명시된 선택 정답과 문맥 이유를 제공한다.
- 제한된 변형은 복수 예문·문장부호·대소문자·주요 축약형을 정규화해 `matched`로 기록한다. 일부 명시된 구조 오류(did 뒤 과거형, more cheaper, should to, 간접 질문 중복 어순, if will rain)는 이유를 안내한다. 나머지 표현은 `compare`로 보류하고 “다른 자연스러운 표현일 수 있어 자동 오답 처리하지 않았다”는 안내를 한다. 모든 영어 문법을 평가한다고 주장하지 않는다.
- 자유 답변은 예문과 다르거나 같아도 `compare`다. 문법·자연스러움 자동 판정은 없다. 질문의 의도/시간/상황, 수업 구조, 두 문장 이상의 이유·세부 내용을 자기 확인한다. 자기 확인과 다시 연습할 부분을 별도 기록한다.
- 입력 없이 비교/성공 진행은 불가하나 연습을 건너뛸 수 있다. skipped는 성공이나 오류로 계산하지 않는다. 입력·단계·피드백·힌트가 재개되며 피드백/예문을 본 뒤 수정하면 도움받은 시도로 남는다.

### 지연 회상과 보존

수업 완료는 경험 기록이고 회상 성공을 만들지 않는다. 수업마다 회상2개를 두 번째 설정 간격(기본3일) 뒤에 `unconfirmed`로 예약한다. 다음 학습 앞이나 별도 복습에서 최대2개, 영어 정답 없이 한국어 상황부터 제시한다. 제출 전에 힌트/예문을 본 기록 또는 어려움은 첫 간격(기본1일)으로 다시 확인한다. 힌트 없는 자기 확인은 기한이 된 이후 다른 현지 날짜에만 간격을 늘린다. 같은 날 재수강으로 기존 예약을 뒤로 밀지 않는다. 건너뛴 복습의 기존 날짜는 그대로다. 이 규칙은 최적 학습법으로 검증된 수치가 아니다.

저장 형식3은 `course`에 새 단계·입력·진단·건너뜀·시도·완료·회상을 분리해 추가한다. v2의 단어·기초 active/입력/힌트/시도/완료/설정/날짜는 그대로, v1은 동결 validator를 거쳐 기존 이관 후 새 과정만 비운다. 읽기만으로는 쓰지 않는다. 첫 v2→v3 저장 전 정확한 raw 원본을 `my-en:migration:v2`에 보존하고 보관 실패 시 새 저장을 중단한다. v1 원본 보관은 유지하며 기존 저장키·직전 백업도 그대로다. 구버전으로 v3 백업을 읽는 것은 지원하지 않는다.

## 첫 코스 검토

2026-10-04 직접 작성 후 문장·한국어 의미 대응, 상황의 자연스러움, 정답 중복, 표현 수, 이전 표현 재사용 순서를 검토했다. 정답 보기는 한 개이며 비슷한 단어를 무작정 함정으로 사용하지 않는다. 자동 구조 검증 통과. 사용자는 기존 내용이 너무 쉽다고 피드백했다. 영어 교육 전문가 검토와 사람의 음질/발음 청취 검토는 아직 없다.

| 수업 | 작은 목표 | 새 표현 | 재사용 |
|---|---|---|---|
| 1 | 인사·이름·재요청 | Hello. / I'm Ryu. / Say that again, please. | 없음 |
| 2 | 반가움·감사 | Nice to meet you. / Thank you. | 인사·이름 |
| 3 | 물·커피 요청 | Water, please. / Coffee, please. | 감사 |
| 4 | 가격·카드 결제 | How much is it? / Can I pay by card? | 커피·감사 |
| 5 | 화장실 위치·거리 | Where is the restroom? / Is it near here? | 재요청 |
| 6 | 내 상태·휴식 | I'm hungry. / I need a break. | 물 |
| 7 | 제안 응답·작별 | That sounds good. / See you tomorrow. | 반가움·감사 |

Ryu는 연습용 이름임을 안내한다. 첫날 재요청 표현은 다른 표현보다 길지만 놓친 말을 다시 요청할 수 있도록 포함했다. 어려우면 단어 조합/문장 힌트/회상 재보기를 쓸 수 있다. 추후 실제 난이도에 따라 “Again, please.” 등 더 짧은 표현으로 버전을 나눠 교체할 수 있다. 글자 음역을 외워 발음한 것으로 판정하지 않는다.

## 단어에서 문장으로 · 2026-10-08

기존 15개 표현에 연결되는 핵심 어휘 16개를 직접 작성했다. 단어별 한국어 뜻·설명·독립 WAV·예문 연결을 제공한다. 새 단어는 하루 2개부터 시작하며 설정에서 1~3개로 바꿀 수 있다. 정규 공부의 기한 도래 단어 복습은 최대 2개, 짧은 공부는 복습 1개+새 단어 1개 이내다. 같은 날 여러 번 공부해도 새 단어 수는 하루 설정을 넘지 않는다. 중간에 미룬 단어의 미완료 방향은 다시 제공한다. 이 수량이나 학습 비율을 검증된 최적값으로 주장하지 않는다. 실제 사용자 부담에 맞춰 조절한다.

단어 음성은 선택이며 기본 진행 버튼으로 텍스트만 보고도 완료할 수 있다. 새 단어는 뜻·소리와 예문 → 영어를 보고 한국어 뜻 선택 → 한국어 뜻을 보고 영어 단어 직접 쓰기 → 같은 단어를 포함한 짧은 문장으로 이어진다. 영어 회상은 대소문자와 끝 문장 부호 차이를 허용한다. 틀리면 설명과 첫 글자/정답 힌트로 다시 시도하며, 오답·힌트를 사용한 방향은 첫 간격으로 재학습한다. 단어의 `meaning`, `production` 기록·간격을 분리한다. 이미 배운 단어의 복습은 기한이 온 방향부터 시작하고, 영어 회상 전에 정답을 먼저 보여주지 않는다. 단어를 미루고 문장으로 바로 갈 수 있다. 음성을 못 들은 것은 별도 건너뛰기로 남기며 어휘 정답을 듣기/발음 능력으로 표시하지 않는다.

모든 단어가 첫 7일에 반드시 끝나는 설계는 아니다. 선택한 수량, 진행·복습 대상과 건너뛰기에 따라 관련 단어를 다음 만남에서 제공한다. 처음 도입한 어휘의 전이·음질·학습 효과는 실사용 검증이 남아 있다. 외부 AI, 음성 전송, 발음 점수는 사용하지 않는다.

## 단계와 기록의 의미

단어 확인 뒤 문장에서는 다음 단계를 사용한다. 진행 중이던 v1 수업은 같은 단계에서 계속한다.

1. 듣기: 영어와 한국어 뜻을 같이 확인하고 포함 음성을 버튼으로 듣는다. 끝까지 재생한 뒤 뜻 선택으로 진행. 기술 문제는 듣기 확인을 건너뛴 별도 기록.
2. 뜻 선택: 모범 문장을 가리고 한국어 의미 선택. 재생 가능. 뜻 힌트에는 정답을 명시하되 사용 횟수 저장. 잘못 골라도 다시 시도.
3. 문장 조합: 한국어 의미를 보고 순서가 바뀐 영어 단어를 누른다. 힌트로 전체 문장 확인 가능. 조합 정답은 **말하기 숙달로 계산하지 않음**.
4. 따라 말하기: 문장/뜻/모범 음성을 보고 따라 말한다. 선택 녹음과 자기 재생. “따라 말했어요”는 자기 확인이며 성공 발음 점수 없음. 건너뛰기 가능.
5. 회상: 한국어 의미만 제시. 영어 문장/모범 음성을 가린다. 스스로 떠올림/어려움/다시보기/건너뛰기. 다시보기를 쓰면 힌트 없는 회상 성공으로 계산하지 않음.

`reading`: 문장 조합의 오답·힌트를 반영하는 기록이며 독해 능력 점수가 아니다. `listening`: 실제 음성을 들은 후 뜻 선택 시도, 오답/뜻 힌트 여부로 다음 복습 간격 조정. `speaking`: 자기 확인 연습 횟수만 저장, 성공 점수 없이 1일 뒤 재확인. `recall`: 자기 확인+힌트 여부로 간격 조정. UI에는 말하기·회상의 자기 확인 성격을 명시한다. 네 상태를 합쳐 “완전 숙달”로 표시하지 않는다.

정규 수업은 새 표현 2~3개 + 이전/기한 도래 표현 최대 2개. 그날 정규 수업을 마친 뒤 다시 누르면 복습/재연습을 제공. 5분 모드·별도 복습 완료는 당일 정규 수업을 막지 않는다. 5분 모드는 최대 2개, 정규 수업 완료 수에 포함 안 함. 결석 기간만큼 분량이 커지지 않는다. 기초 모드는 시간을 제한하지 않는다. 새 설명·응용 과정은 위의 실제 내용과 응용량으로 15~25분을 목표로 한다.

## 복습/데이터 계약

- 초기 간격 `[1,3,7,14]`은 조절 가능한 운영 규칙. 첫 성공 후 1일, 예약일 이후 다른 현지 날짜에 성공하면 3일, 7일, 14일; 이후 14일 유지. 당일 반복·예약 전 재연습으로 간격을 늘리지 않는다. 오답/어려움/힌트 사용은 첫 간격으로 재시작. 성공 후 추가 연습에서 오답이 나오면 재학습을 앞당긴다. 표현 복습은 기한이 온 skill만 선택하므로 따라 말하기가 매일 필요해도 다른 단계를 매일 반복시키지 않는다. 4개 양의 증가 정수, 최대 90일.
- 브라우저/마이크 실패의 건너뛰기는 skill 오답/퇴보로 계산하지 않으며 기존 해당 skill 예약도 바꾸지 않는다.
- `lesson.id/version`, `phrase.id/version`, `schemaVersion` 분리. `Attempt`: session, lesson/phrase 버전, step, outcome, hints, 시각. `Review`: phrase+skill 키, stage/due/lastAt/lastSession, evidence, successes/practices. `Session`: 순서·현재 표현·단계·힌트·선택 단어. `Completion`: session/lesson/version/mode/표현/day/timeZone.
- 날짜는 처음 저장한 IANA 시간대의 현지 날짜. 간격은 UTC 날짜 산술로 날짜만 더해 DST의 23/25시간 영향을 피함. 자정을 넘겨 완료하면 완료한 날 기록. 시간대 변경 시 기존 due의 달력 날짜는 유지, 이후 예약에 새 시간대 적용.
- 완료 세션 중복 방지. 직전 정상 저장본 하나 보관. 손상/미지원 콘텐츠 버전의 자동 덮어쓰기 금지. JSON 복원은 Zod로 검증 후 사용자 확인. 녹음은 영속화하지 않음.
- 수업/표현 버전을 실제로 올릴 때 이전 state migration을 먼저 설계해야 한다. 현재 schemaVersion 3. 새 설명·응용 과정은 위의 보존 계약을 따른다. v1은 별도 동결된 validator로 검증 후 이관하며 기존 active 단계·선택 단어·힌트·시도·완료·예약 날짜·누적 횟수를 보존한다. v1에 없던 단어 기록/문장 조합 skill을 성공으로 만들어 내지 않는다. 기존 1회 저장본과 별도로 첫 이관 원본을 `my-en:migration:v1`에 보관한다. 원본 보관 실패 때 이관 저장도 중단한다. 기존 키 `my-en:progress:v1`, `my-en:previous:v1`을 유지한다. v2 이관·v3 백업 round trip 지원, 미지원 형식은 원본 보존/내보내기로 처리한다. v2 백업을 이전 코드로 되돌려 읽는 것은 지원하지 않는다.

## 8모듈 확장 로드맵

기존 기초 스키마의 `ModuleId`와 `modules` 목록이 경계다. 새 실용/확장 13수업은 별도 `course` 경계에서 실제 제공한다. 각 모듈은 대표 상황 + 하루 2~3표현 lesson + 재사용 reference + 음성 자산을 추가한다. 미래 콘텐츠는 아직 수업으로 제공하지 않는다.

| 모듈 | 다음 작은 목표 |
|---|---|
| 인사 | 도움 부탁, 대화 시작/재요청 |
| 숫자·시간·자기소개 | 시간·출신·나이, 숫자 듣기 |
| 카페 주문 | 크기/온도/포장, 상대 질문 듣기 |
| 일상 | 하루 행동과 상태 |
| 취미 | 좋아하는 활동 묻고 답하기 |
| 길 묻기 | 좌우/직진을 듣고 다시 확인 |
| 쇼핑 | 크기/색상/가격/결제 요청 |
| 약속 | 날짜/시간/장소 정하기 |

기초 모듈 확장은 기존 범위를 유지한다. 새 실용/확장13수업은 실제 사용 시간·난이도·설명/응용 효과를 사용자 체험과 교육 전문가 검토로 조정한다. 사용자 이름/관심 주제 설정과 새 수업의 재배포 가능한 음성은 후속 과제다. 계정/동기화/외부 AI는 필요가 확인되고 비용·개인정보 승인 범위가 정해진 뒤 별도 설계한다.
